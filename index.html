Multi-Level News Video Classification

A research project investigating multi-label classification of news videos across content format, source type, primary language, geography, and production attributes using complementary metadata and visual approaches.

▶ Watch Presentation Explore Architecture ↓
Project focus Understanding news videos through multiple attributes rather than a single category, with a visual pipeline as the main implemented approach and a metadata pipeline as an experimental baseline.

Core Logic

The ideas behind the implementation.

The project combines classical text representation with pretrained visual representations. The equations below summarize the core mathematical ideas used by the experimental and visual workflows.

Metadata · TF-IDF

Text feature weighting

TF-IDF represents the importance of a term in a document relative to how frequently that term occurs across the dataset.

TF-IDF(t,d) = TF(t,d) × IDF(t)
Visual · Shot Segmentation

Histogram-based frame comparison

Consecutive sampled frames are compared through their visual distributions to identify transitions between shots.

DB(p,q) = √(1 − Σi √(piqi))

08 · Limitations

What the current system does not yet capture.

The current implementation is intentionally scoped around the available visual and metadata signals. Several modalities remain outside the final pipeline.

01

Audio

Audio and speech transcripts are not integrated into the current visual pipeline.

02

OCR

On-screen text extraction has not yet been incorporated into the current system.

03

Class imbalance

Minority classes remain challenging because some categories have limited examples.

04

Visual-only signals

Some attributes, especially language, may not be reliably inferred from frames alone.

05

Dataset scale

The current dataset is relatively small for a broad multi-attribute video classification problem.

06

Separate pipelines

The metadata and visual approaches are not yet fused into a single multimodal model.
