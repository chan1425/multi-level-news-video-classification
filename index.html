Multi-Level News Video Classification

A multi-label classification framework for analysing news videos across content format, source type, primary language, geography, and production attributes using complementary metadata and visual approaches.

01 · Project

Understanding news videos beyond a single label.

The project investigates how different information sources can be used to classify news videos across multiple semantic and production-level attributes. The work began with a metadata-based proof of concept and progressed to a visual classification pipeline using representative video keyframes and pretrained visual representations.

Multi-Label Classification

Predicts five target attributes rather than reducing a news video to a single category.

Visual Understanding

Uses representative keyframes and DINOv2 visual embeddings to obtain video-level representations.

DINOv2-Small was selected as the final visual backbone because it provided a richer pretrained visual representation for the project's semantic video understanding task, while MobileNetV3-Small provided a lighter and faster alternative.

Metadata Baseline

What the metadata experiments showed.

The metadata pipeline was initially evaluated as a proof of concept. YouTube metadata was transformed using TF-IDF and classical machine-learning models were investigated.

Initial Geography Baseline

TF-IDF with Logistic Regression achieved 60% test accuracy, with a 0.44 macro F1-score and 0.53 weighted F1-score.

Dataset Expansion

The annotated metadata dataset was expanded from 20 to 50 videos during the baseline experimentation.

Key Limitation

Severe class imbalance made fine-grained metadata-only classification difficult, particularly for less represented categories.

Limitations

What the current system does not yet capture.

The current visual pipeline focuses on visual information. Certain attributes, especially primary language, may require information that cannot reliably be inferred from frames alone.

Audio

Audio and speech transcripts are not currently integrated into the visual pipeline.

OCR

On-screen text extraction has not yet been incorporated into the current system.

Class Imbalance

Minority classes remain challenging because of limited examples in some categories.

05 · Future Work

Towards multimodal news understanding.
